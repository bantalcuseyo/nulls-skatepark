# M1 — Skate core

Read: `spec/07_gameplay.md` (§7.1 controls, §7.2 state machine, §7.3 physics, §7.9 feel),
`spec/03_tech_foundation.md`, `PROGRESS.md`.

## Deliverable
Skater controller (push / roll / brake, variable-height ollie), camera follow, fixed timestep at
60 Hz with render interpolation. Input layer: keyboard, gamepad, and touch overlay built against
the M0 input contract.

## Files
- `src/sim/SkaterSim.ts`, `src/sim/StateMachine.ts`, `src/sim/Physics.ts`, `src/sim/FixedStep.ts`
- `src/systems/InputManager.ts`, `src/systems/TouchControls.ts`, `src/systems/CameraRig.ts`
- `src/entities/Skater.ts`, `src/scenes/Game.ts`, `src/scenes/Hud.ts`
- `tools/gen_art.py` (skater sprite sheets + placeholder board)
- `data/physics.json`

## Acceptance checks
- [ ] Responsive controls, no jitter
- [ ] Ollie apex 63–96 px (measured headless: tap vs held)
- [ ] Input latency within 1 frame (buffered 6–8 frames)
- [ ] Touch buttons are multi-touch (several held at once)
- [ ] Coyote time + jump buffer active
- [ ] Fixed timestep with interpolation; no simulation drift
